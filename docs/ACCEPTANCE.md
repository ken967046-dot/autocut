# Windows 實機驗收清單（約 30 分鐘）

軟體的核心（剪輯規則、渲染、介面操作）已在 Linux 無頭環境用自動測試驗證過，細節見 `TASKS.md`。
**但這些測試沒辦法代替你的電腦**：真正的 Windows 視窗、檔案總管拖放、中文輸入法、螢幕縮放、字型、顯示卡編碼器、
真實手機／相機拍的素材，都只有在你的電腦上才驗得到。這份清單就是補這一塊。
每一步都寫了「應該看到什麼」；看到不一樣的，就是要回報的問題。全部過了，核心才算驗收，之後才會做選用外掛「動態圖層」。

## 先準備
- 一支橫式長影片（1 分鐘以上，最好有人說話）。
- 三支以上的短毛片（手機或相機直接拍的，不要先轉檔）。
- 一個**路徑含中文和空格**的資料夾，把上面的檔案放進去（例如 `D:\剪輯 測試\素材\`）。

## A. 安裝與啟動
1. 解壓縮 zip，雙擊 `Setup-AutoCut.bat`。
   應該看到：最後有「完成」字樣、桌面多一個「AutoCut Studio」捷徑。ffmpeg 下載失敗時會明講（不是默默失敗）。
2. 雙擊捷徑（或 `Start-AutoCut.bat`）。應該看到：深色的中文介面視窗。
3. 選單「說明 → 檢查環境…」。應該看到：ffmpeg、libass、libx264、numpy、OpenCV、PySide6 都是「✔ 正常」（faster-whisper、opencc 是「– 選用」）。
   按「偵測硬體編碼器」會實際試跑顯示卡的編碼器，結果請記下來。
4. （可選）在資料夾上按 Shift＋右鍵 →「在此處開啟 PowerShell 視窗」，執行
   `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows\Run-Tests.ps1 -Fast`，把最後幾行貼回來。

## B. 拖放與手動剪輯
5. 把橫式長影片**從檔案總管直接拖進視窗**。應該看到：素材庫出現縮圖，上方橫幅「要自動剪成 9:16 短影音嗎？」。先按「放到時間軸」。
6. 時間軸上操作：點一下時間尺移動播放頭 → 按 `S` 分割；拖片段左右邊緣修剪；拖片段本體移動；
   `Shift+Delete` 波紋刪除（後面的片段補位）；`Ctrl+Z` 復原、`Ctrl+Y` 重做。每一步都應該立刻在預覽看得到。
7. 點一個片段，在右側「檢查器」改音量、淡入淡出、速度。在數字框輸入數字按 `Enter` 之後，**直接按 `Ctrl+Z`**：
   應該復原的是剛才的剪輯（不是只復原數字框裡的字）；再按方向鍵或空白鍵，應該是操作時間軸／播放。
   （這是鍵盤焦點的修正，我只用模擬按鍵測過，請用真的鍵盤確認。）
8. 在字幕文字框用**你平常的中文輸入法**打字（注音／倉頡…）。應該看到：組字視窗出現在游標旁，按 Enter 後文字進入字幕，不會跳掉或亂碼。
   （輸入法完全沒測過。）
9. 拖第二個、第三個影片進來，再用 `Ctrl+S` 存檔、關閉、重新開啟（「檔案 → 開啟最近的專案」）。內容應該完全一樣。

## C. 自動剪輯
10. 「自動剪輯 → 自動剪成短影音…」→ 設定 → 「開始分析」。結果頁應該列出每一支候選（縮圖、長度、為什麼選它、審核意見）；
    按「預覽此段」會跳出小視窗播放；取消勾選不要的，按「套用選取的片段」。**一次 `Ctrl+Z` 應該整批復原。**
11. 套用後到時間軸逐段修正：9:16 的取景框有沒有抓到人、要不要改關鍵格。
12. 「自動剪輯 → 自動合併成長片…」，用三支毛片試。
13. **品質由你判斷**：自動剪輯是啟發式規則（不是看得懂劇情的模型），請記下哪裡不滿意（選段、取景、順序、轉場）。這是回報最有用的部分。

## D. 輸出與檢查
14. `Ctrl+E`。選「短影音 9:16」→ 開始輸出。完成後會出現「技術檢查通過」之類的結果；**人工審片一律先顯示「尚未審片」**，要你按「通過／需修改／退回」才會變。
15. 用你平常的播放器看成品：嘴型和聲音有沒有對上、字幕字型（預設微軟正黑體）、9:16 構圖、結尾有沒有被截掉。
16. 輸出設定的編碼器選「自動」。有 NVIDIA／Intel／AMD 顯示卡的話，應該用硬體編碼；不能用時會自動改用 CPU 並完成輸出（不會卡住）。

## E. 其他
17. 把 Windows 的「縮放」調成 125%、150% 再開軟體。介面不應該破版或字被截掉。
18. 用工作管理員強制結束軟體（正在編輯、還沒存檔時），再開一次。應該被詢問要不要復原自動存檔。
19. 把整個專案資料夾搬到另一個位置，再開專案檔。素材找不到時，用素材庫右鍵「重新連結…」。

## 回報時請附
- 是第幾步、看到什麼（截圖最好）。
- 選單「說明 → 開啟資料與記錄資料夾」會打開 `%LOCALAPPDATA%\AutoCutStudio`，把裡面 `logs` 資料夾的 `gui.log` 一起給我。
- 有跑第 4 步的話，貼上最後幾行。
